## About

I'm a software engineer and product builder focused on full-stack development, applied AI, and building software from the ground up. As CTO & Co-Founder at **SIKE Technologies**, I work on turning product ideas into reliable digital experiences.

I enjoy working across the product lifecycle: understanding the problem, shaping the experience, designing the architecture, implementing the system, and improving it through testing and iteration.

- **Building:** AI-enabled products, web applications, and practical software tools
- **Focus:** Full-stack engineering, Python, JavaScript/TypeScript, APIs, and AI integrations
- **Approach:** User-first products, maintainable systems, and engineering decisions grounded in real needs
- **Based in:** India
